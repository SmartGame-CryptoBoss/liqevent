Кейси / Щорічна зустріч

01 / КОРПОРАТИВНА ЗУСТРІЧ

Дводенна щорічна зустріч для близько 200 учасників — підготовка за два дні

Близько 200учасників
Два днітривалість заходу
Два днідо старту на підготовку

Задача

Організувати повноцінну дводенну щорічну зустріч приблизно для 200 учасників. Підготовку потрібно було зібрати фактично за два дні до старту заходу.

ВІД ПІДГОТОВКИ ДО РЕАЛІЗАЦІЇ

Що зробив
LIQ EVENT

LIQ EVENT взяв на себе повну організаційну координацію: розробив концепцію, знайшов підрядників, залучив декораторів і технічну команду, ведучого та кавер-бенд. Підготував ведучого й разом із ним розробив сценарій, склав загальний таймінг, сценарії та технічні сценарії для підрядників. Координував підготовку й реалізацію заходу.

01 / ВИКЛИК

Складність

За два дні потрібно було практично з нуля підтвердити ключових підрядників, зібрати концепцію, сценарну й технічну частини та синхронізувати людей, які раніше не працювали разом у межах цього проєкту.

02 / ПІДХІД

Рішення

Підготовку розділили на паралельні робочі потоки: підрядники, технічний продакшн, декор, ведучий, музична програма та сценарна частина. Для команд підготували таймінги, сценарії й технічні задачі, після чого звели їх у єдиний план реалізації.

ПОДІЯ В КАДРАХ

РЕЗУЛЬТАТ

Дводенний захід для близько 200 учасників реалізували в заплановані строки. Після цього клієнт замовляв LIQ EVENT для організації заходів ще наступні два роки.

Масштаб проєкту

Два дні заходу · близько 200 учасників · фактично два дні до старту на підготовку.
